# dispose

개체에서 사용하는 리소스를 해제합니다.

```text
dispose ()
```

## 매개변수

없음.

## 반환 값

없음.

## 비고

이 방법은 가비지 수집기나 스크립트 끝에 개체가 완료되기를 기다리지 않고 개체에서 사용하는 리소스를 확보하는 데 유용합니다.

## 기능

**클래스의 메서드:** [HttpSoapConnection](c-httpsoapconnection.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
