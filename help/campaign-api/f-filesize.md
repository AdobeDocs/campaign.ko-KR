# 파일 크기

파일 크기를 바이트 단위로 반환합니다.

```text
fileSize (filename)
```

## 매개변수

**파일 이름** 파일의 전체 이름입니다.

## 반환 값

오류가 발생한 경우(예: 파일을 찾을 수 없는 경우) 파일 크기 또는 -1을 반환합니다.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
