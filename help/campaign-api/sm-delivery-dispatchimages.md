# 이미지 발송

애플리케이션 서버에서 이미지를 중간 소싱 서버에 전송하도록 명령합니다.

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## 매개변수

**이미지** 중간 소싱 서버에 업로드할 이미지 목록입니다.

**providerId** 게재 라우터 식별자.

**providerName** 게재 라우터 이름.

## 반환 값

없음.
