# RegisterInstance

추적 인스턴스 승인에 사용됨

```text
RegisterInstance ( String instanceName, String dbId, String lang )
```

## 매개변수

**instanceName** 승인할 인스턴스의 이름

게재를 수행하는 고객의 **dbId** 데이터베이스 식별자

**lang** 인스턴스 언어

## 반환 값

없음.
