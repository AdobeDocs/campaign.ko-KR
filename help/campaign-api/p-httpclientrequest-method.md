# 방법

문자열 형식의 HTTP 메서드

```text
method
```

## 비고

이 재산의 가액은 제도적으로 대문자 값으로 변경된다. 예:

```javascript
var http = new HttpClientRequest(url)
http.method = "SEARCH"
```

## 기능

**클래스의 속성:** [HttpClientRequest](c-httpclientrequest.md)

**읽기 전용:**

아니요

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
