# HttpServletResponse(클래스)

클라이언트로 반환되는 서블릿의 응답을 나타냅니다.

`response` 변수가 액세스할 수 있는 이 클래스의 인스턴스는 하나만 있습니다.

## 방법

| 방법 | 설명 |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | 응답의 문서 유형을 변경합니다. |
| [sendRedirect](m-httpservletresponse-sendredirect.md) | 다른 URL로의 임시 리디렉션을 반환합니다. |
| [addCookie](m-httpservletresponse-addcookie.md) | 응답에 쿠키를 추가합니다. |
| [addHeader](m-httpservletresponse-addheader.md) | 응답에 추가 HTTP 헤더를 추가합니다. |
| [sendError](m-httpservletresponse-senderror.md) | 매개 변수로 전달된 오류 코드를 사용하여 오류 응답을 반환합니다. |

## 기능

**다음 위치에서 사용 가능:**

* JSSP
* 웹 앱
