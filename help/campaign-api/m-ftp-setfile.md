# setFile

> 경고:
>
> 파일 API를 통한 액세스는 Adobe Campaign의 **var**, **sftp** 및 임시 폴더로 제한됩니다.

전송 모드 및 수신 파일을 정의합니다.

```text
setFile (filename)
```

## 매개변수

**파일 이름** 로컬 파일의 이름입니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [FTP](c-ftp.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
