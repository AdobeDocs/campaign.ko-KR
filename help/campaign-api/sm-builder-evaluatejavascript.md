# EvaluateJavaScript

JavaScript 코드 평가.

```text
XML context = EvaluateJavaScript ( String name, String script, XML context )
```

## 매개변수

**이름** 스크립트 이름.

실행할 **스크립트** 스크립트 코드.

테스트의 **컨텍스트** 실행 컨텍스트입니다.

## 반환 값

테스트의 **컨텍스트** 실행 컨텍스트입니다.
