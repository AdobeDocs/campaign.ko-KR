# 상위 값 선택

상위 n개의 값을 복구합니다.

```text

```

## 매개변수

분석의 **스키마** 루트 스키마

**expr** Source 식

**classCount** 생성할 빈 수

## 반환 값

**selectedValues** 값 목록
