# sendRedirect

다른 URL로의 임시 리디렉션을 반환합니다.

```text
sendRedirect (location)
```

## 매개변수

**위치** 리디렉션 URL.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [HttpServletResponse](c-httpservletresponse.md)

**다음 위치에서 사용 가능:**

* JSSP
* 웹 앱
