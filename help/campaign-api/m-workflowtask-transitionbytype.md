# transitionByType

지정된 유형에 해당하는 전환을 반환합니다.

```text
transitionByType (type)
```

## 매개변수

전환의 **type** 유형입니다.

## 반환 값

유형이 매개 변수로 전달되도록 하는 첫 번째 전환이며, 활동에 이 유형의 전환이 없는 경우 null입니다.
