# 지시어 페이지

함수 또는 문자열 라이브러리를 포함합니다.

## 구문

&lt;%@ page import=&quot;lib1, ...&quot; %> &lt;%@ page stringGroup=&quot;groupName&quot; %>

## 설명

문자열 라이브러리를 가져오면 이름이 sg\_로 시작하는 전역 JavaScript 개체와 특수 문자가 &#39;\_&#39;로 대체된 라이브러리의 이름이 노출됩니다. 예를 들어 nms:campaign을(를) 포함하면 sg\_nms\_campaign 변수가 만들어집니다.

## 예제

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
