# EvaluateJavaScriptTemplate

JavaScript 템플릿(JST) 평가.

```text
[ XML context, String result ] = EvaluateJavaScriptTemplate ( String name, String template, XML context )
```

## 매개변수

**이름** 스크립트 이름.

평가할 **템플릿** 문서.

문서를 평가할 때 **컨텍스트** 컨텍스트를 사용합니다.

## 반환 값

문서를 평가할 때 **컨텍스트** 컨텍스트를 사용합니다.

평가 결과 **결과** 문서.
