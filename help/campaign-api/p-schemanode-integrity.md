# 무결성

링크 무결성 유형을 반환합니다.

```text
integrity
```

## 비고

속성은 다음 값 중 하나를 사용할 수 있습니다.

* Schema.INTEGRITY\_NORMAL - &quot;일반&quot; 유형 링크입니다.
* Schema.INTEGRITY\_DEFINE - &quot;정의&quot; 유형 링크입니다.
* Schema.INTEGRITY\_NEUTRAL - &quot;neutral&quot; 유형 링크입니다.
* Schema.INTEGRITY\_USED - &quot;used&quot; 유형 링크입니다.
* Schema.INTEGRITY\_OWN - &quot;고유&quot; 유형 링크입니다.
* Schema.INTEGRITY\_OWNCOPY - &quot;owncopy&quot; 유형 링크입니다.

**클래스의 속성:** [SchemaNode](c-schemanode.md)
