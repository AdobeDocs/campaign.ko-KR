# CreateExportList

장바구니의 항목을 내보낼 목록을 만듭니다.

```text
Number listId = CreateExportList ( String label, Number folderId )
```

## 매개변수

목록의 **레이블** 레이블

목록이 생성될 폴더의 **folderId** ID입니다(기본 폴더를 사용하려면 0).

## 반환 값

새로 만든 목록의 **listId** ID
