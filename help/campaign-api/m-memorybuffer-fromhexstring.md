# fromHexString

버퍼에 16진수 문자열의 콘텐츠를 로드합니다.

```text
fromHexString (string)
```

## 매개변수

**string** 16진수로 인코딩된 이진 데이터를 나타내는 문자열로, 버퍼에 추가됩니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [MemoryBuffer](c-memorybuffer.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
