# XML 사용

많은 JavaScript API는 XML 유형 개체를 매개 변수로 사용하거나 반환합니다. 이전 버전의 Adobe Campaign에서는 XML 요소를 언어에서 직접 조작할 수 있도록 하는 JavaScript E4X 확장 기능을 사용했습니다. 그러나 이 기술은 서서히 포기되고 있다.

이 기술을 대체하기 위해 XML 문서를 조작하는 새 개체가 추가되었습니다. 일부 확장자를 사용하여 DOM(문서 개체 모델) 인터페이스의 하위 집합을 다시 시작합니다. 표기법 객체를 사용하여 XML 문서를 쉽게 만들 수도 있습니다. 이는 JXON BadgetFish 규칙의 간소화된 버전입니다.

## DOM 인터페이스

[DOMDocument](c-domdocument.md) 개체가 XML 문서입니다. 문자열 문자, JXON 개체 또는 파일에서 직접 만들 수 있습니다. 다음은 DOM 문서를 만드는 예제입니다.

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

이 인터페이스는 다음과 같은 다양한 주목할 만한 차이점과 함께 W3C 사양의 일부를 인식합니다.

* getElements\* 함수와 childNodes 및 속성 속성은 NodeList 개체가 아닌 JavaScript 테이블을 반환하므로 테이블의 자체 함수인 forEach, map, ... 를 사용할 수 있습니다.
* 값이 지정되지 않은 경우 특정 속성은 null이 아닌 빈 문자열을 반환합니다.

또한 특정 유틸리티 함수와 일부 비표준 확장이 추가되었습니다. 예를 들어 속성을 읽거나 수정하려면 다음을 작성하기만 하면 됩니다.

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

대신:

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

$name 속성을 사용하여 속성을 할당하면 문자열, 부울, 날짜 또는 숫자를 사용할 수 있습니다. 값은 자동으로 문자열로 변환됩니다.

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## 제이슨

JXON은 JavaScript 개체가 XML 문서를 쉽게 작성할 수 있는 표기법 규칙입니다. 이 표기법을 사용하여 가능한 모든 XML 문서를 만들 수는 없습니다. 예를 들어 속성과 이름이 같은 요소를 지정할 수 없으며 네임스페이스는 관리되지 않습니다. Adobe Campaign 문서에 적용됩니다. 보다 복잡한 경우 항상 기존 DOM 함수(요소별로 요소를 구문 분석하거나 생성)를 사용할 수 있습니다. XML 객체는 속성이 요소 및 속성과 일치하는 JavaScript 객체로 표시됩니다. 값 유형은 요소와 관련되는지 아니면 속성과 관련되는지를 결정합니다.

* 문자열 값이 문자열인 속성
* 부울 값이 &#39;true&#39; 또는 &#39;false&#39;인 속성
* 숫자 값이 십진수 표현인 속성
* 날짜 날짜 및 시간의 ISO-8601 표현인 값을 갖는 속성
* 개체 A 요소
* 요소 목록 배열 A

$ 라는 이름의 특수 속성이 요소의 텍스트 컨텐츠에 사용됩니다. 예:

> **JXON:**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML:**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML:**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML:**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML:**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

속성에 잘못된 JavaScript 식별자인 특수 문자가 포함되어 있는 경우 따옴표로 묶어야 합니다.

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

JXON 개체는 함수가 문서 또는 XML 요소를 예상하는 모든 위치에서 인수에 사용할 수 있습니다. 예제:

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

는 다음과 같습니다.

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

XML 문서를 조작하는 작업은 DOM 개체에 의해 수행되며, JXON 개체는 초기화에 대해서만 사용되는 유틸리티입니다. 특히 문서에 변수 부분이 포함된 경우 리터럴 JavaScript 구조에서 XML 문서를 만드는 것이 더 유용합니다.
