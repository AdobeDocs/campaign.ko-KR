# GenerateAndSaveReport

서버에서 보고서를 생성하여 데이터베이스에 저장

```text
XML result = GenerateAndSaveReport ( String reportName, XML context )
```

## 매개변수

보고서의 **reportName** 내부 이름

**컨텍스트** 보고서 구성

## 반환 값

**결과** 고유 식별자 및 레코드 날짜
