# 날짜/시간

datetime 형식 컨트롤을 사용하면 날짜와 시간을 입력할 수 있습니다.

![DateTime 컨트롤](assets/datetime.b1989ea6.png)

## 속성

**backColor - string** 배경색(btnshasow, white).

**border - string** 컨트롤의 테두리 스타일을 변경합니다(단색, 이중, 삽입, 시작, 없음).

**font-size - integer** 글꼴 크기를 변경합니다.

**레이블 - 문자열** 관련 레이블입니다.

**nolabel - 부울** 연결된 레이블을 숨깁니다.

**읽기 전용 - 부울** 컨트롤을 읽기 전용으로 강제 실행합니다.

**필수 - 부울** 필드는 필수입니다.
