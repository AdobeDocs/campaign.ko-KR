# 속성

노드가 요소인 경우 속성 목록을 포함하는 테이블을 반환하고, 그렇지 않으면 null을 반환합니다.

```text
attributes
```

## 비고

이 속성은 각 액세스에 대해 새 테이블을 만듭니다. 따라서 속성을 여러 번 액세스하는 것보다 테이블을 로컬 변수에 유지하는 것이 좋습니다.

## 기능

**클래스의 속성:** [DOMNode](c-domnode.md)
