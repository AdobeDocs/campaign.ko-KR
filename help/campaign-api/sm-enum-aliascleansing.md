# 앨리어스 정리

정리된 열거를 사용하여 데이터베이스를 업데이트합니다.

```text
AliasCleansing ( XML where, Date fromDate, Boolean refreshHit, Boolean resetHit )
```

## 매개변수

**where** 열거형 필터.

설문 조사 응답의 **fromDate** 시작 날짜입니다.

**refreshHit** 히트 업데이트.

**resetHit** 히트가 처음부터 업데이트되었습니다.

## 반환 값

없음.
