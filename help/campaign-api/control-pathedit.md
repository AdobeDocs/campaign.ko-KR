# 경로 편집

필드를 선택하도록 제어합니다.

## 속성

**backColor - string** 배경색(btnshadow, white).

**border - string** 컨트롤 윤곽선 스타일(단색, 이중, 인세트, 시작, 없음)을 변경합니다.

**font-size - integer** 글꼴 크기를 변경합니다.

**hideCalculated - boolean** 계산된 필드를 숨깁니다.

**hideMappedAsXml - 부울**&#x200B;에서 XML 필드를 숨깁니다.

**레이블 - 문자열** 관련 레이블입니다.

**nolabel - 부울** 연결된 레이블을 숨깁니다.

**noTransaction - 부울** 트랜잭션 모드를 사용하지 않습니다.

**읽기 전용 - 부울** 컨트롤을 읽기 전용으로 강제 실행합니다.

**필수 - 부울** 필드는 필수입니다.

**useLink11Path - boolean**&#x200B;에 1:1 링크가 표시됩니다.

**useTablePath - boolean** 테이블을 표시합니다.

**useUnboundPath - boolean** 컬렉션을 표시합니다.

**xpath - 문자열** 편집할 필드입니다.

**xpathBaseType - xpath** 선택한 필드의 형식을 저장하는 경로입니다.

**xpathDataPolicy - xpath** 선택한 필드의 dataPolicy 속성을 저장하는 경로입니다.

**xpathEnum - xpath** 선택한 필드의 시스템 열거형을 저장하는 경로입니다.

**xpathLabel - string** 선택한 필드의 레이블을 저장하는 경로입니다.

**xpathSchema - string** 스키마 경로.

스키마의 MD5를 저장하는 **xpathSchemaMd5 - xpath** 경로입니다.

**xpathStartPath - string** startPath의 경로(xpathSchema가 정의된 경우에만 사용).

**xpathUnbound - xpath** 선택한 필드의 바인딩되지 않은 속성을 저장하는 경로입니다.

**xpathUserEnum - xpath** 선택한 필드의 자유 열거형을 저장하는 경로입니다.

**xpathType - xpath** 선택한 필드의 기본 제어를 저장하는 경로입니다.

**확대/축소 - 부울** 편집 단추를 표시합니다.
