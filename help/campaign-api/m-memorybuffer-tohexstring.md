# toHexString

버퍼를 16진수 문자 문자열로 변환합니다.

```text
toHexString ()
```

## 매개변수

없음.

## 반환 값

16진수로 인코딩된 버퍼 컨텐츠입니다.

## 기능

**클래스의 메서드:** [MemoryBuffer](c-memorybuffer.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
