# 연산자

현재 연산자에 대한 정보(이름, 식별자, 권한 등)가 포함된 개체를 반환합니다.

```text
operator
```

## 비고

개체 속성에 대한 자세한 내용은 [CurrentOperator](c-currentoperator.md) 클래스를 참조하십시오.

## 기능

**클래스의 속성:** [응용 프로그램](c-application.md)

예
