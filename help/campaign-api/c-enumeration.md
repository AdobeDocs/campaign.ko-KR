# 열거형(클래스)

열거형의 정의를 나타냅니다.

## 속성

| 속성 | 설명 |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | 열거형 형식을 제공하는 문자 문자열을 반환합니다. |
| [기본값](p-enumeration-default.md) | 열거형의 기본값을 제공하는 문자 문자열을 반환합니다. |
| [설명](p-enumeration-description.md) | 열거형에 대한 설명을 제공하는 문자열을 반환합니다. |
| [hasImage](p-enumeration-hasimage.md) | 열거형에 이미지가 있는지 여부를 나타내는 부울을 반환합니다. |
| [레이블](p-enumeration-label.md) | 열거형의 레이블을 제공하는 문자열을 반환합니다. |
| [이름](p-enumeration-name.md) | 열거형의 이름을 제공하는 문자 문자열을 반환합니다. |
| [값](p-enumeration-values.md) | 각 속성이 해당 값으로 인덱싱된 [EnumerationValue](c-enumerationvalue.md) 개체인 개체를 반환합니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
