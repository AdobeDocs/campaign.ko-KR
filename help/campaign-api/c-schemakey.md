# SchemaKey(클래스)

키의 정의를 나타냅니다.

## 속성

| 속성 | 설명 |
| --- | --- |
| [레이블](p-schemakey-label.md) | 키에 대한 간단한 설명을 반환합니다. |
| [설명](p-schemakey-description.md) | 키에 대한 설명을 반환합니다. |
| [이름](p-schemakey-name.md) | 키의 식별자를 반환합니다. |
| [isInternal](p-schemakey-isinternal.md) | 키가 내부 키인 경우 true를 반환합니다. |
| [allowEmptyPart](p-schemakey-allowemptypart.md) | 키의 필드가 비어 있으면 true를 반환합니다(필드 중 하나 이상을 입력해야 함). |
| [필드](p-schemakey-fields.md) | 키의 필드 필드([SchemaNode](c-schemanode.md))를 포함하는 테이블을 반환합니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
