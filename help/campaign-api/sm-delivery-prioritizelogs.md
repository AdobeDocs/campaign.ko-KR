# 로그 우선 순위 지정

게재 목록에 대한 게재 로그의 우선 순위 지정

```text
PrioritizeLogs ( Number id, XML deliveries, String logTable )
```

## 매개변수

**id** 우선 순위 지정 고유 식별자

고려해야 할 게재 **게재** 목록

모든 로그 메시지가 들어 있는 **logTable** 테이블

## 반환 값

없음.
