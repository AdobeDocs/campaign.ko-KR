# renameNode

요소 또는 속성의 이름을 변경합니다.

```text
renameNode (node, namespaceURI, qualifiedName)
```

## 매개변수

**node** 요소/특성 유형 노드입니다.

**namespaceURI** 새 네임스페이스 URI입니다.

**qualifiedName** 새 정규화된 이름입니다.

## 반환 값

노드의 이름이 변경되었습니다. 지정된 노드이거나 이전 노드를 대체하는 노드일 수 있습니다.

## 기능

**클래스의 메서드:** [DOMDocument](c-domdocument.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
