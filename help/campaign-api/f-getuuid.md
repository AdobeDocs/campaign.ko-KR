# getUI

고유 식별자(Universally Unique ID) 생성.

```text
getUUID ()
```

## 매개변수

없음.

## 반환 값

&#39;550E8400-E29B-41D4-A716-446655440000&#39; 유형의 고유 ID가 포함된 문자 문자열입니다.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
