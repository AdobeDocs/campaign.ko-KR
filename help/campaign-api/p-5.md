# 날짜 사용

이 장에서는 서버에서 실행되는 JavaScript 프로그램(워크플로우, JSSP 등)에서 날짜를 조작하는 데 사용할 함수에 대해 자세히 설명합니다.

## 날짜 및 시간대

JavaScript에서 날짜는 UTC로 저장됩니다. 즉, 날짜 구성 또는 내부 디스플레이 또는 저장을 위한 텍스트 문자열로의 변환에 대한 시간대만 걱정하면 됩니다. 날짜 변환에는 두 가지 함수 범주가 있습니다.

* JavaScript 라이브러리의 함수 (date.toString(), date.toLocaleString(), date.getHours(), ...),
* Adobe Campaign 플랫폼의 함수( [formatDate(date, format)](f-formatdate.md) ).

규칙상, 첫 번째는 컴퓨터의 시간대를 사용하고, 마지막 항목은 컨텍스트에 따라 시간대를 사용합니다. 일반적으로 현재 연산자의 시간대이지만 내보내기 또는 워크플로와 같은 경우 이 동작을 수정할 수 있습니다.

## 현재 날짜 얻기

JavaScript에서 현재 날짜를 가져오는 방법에는 두 가지가 있습니다.

* new Date()는 현재 날짜로 초기화된 새 Date 객체를 만듭니다. 날짜는 스크립트가 실행되는 컴퓨터의 시간과 일치합니다.
* [getCurrentDate()](f-getcurrentdate.md)은(는) 데이터베이스 서버의 시간을 기준으로 현재 날짜를 반환합니다.

[getCurrentDate()](f-getcurrentdate.md) 함수는 특히 데이터베이스의 다른 날짜와 비교하거나 데이터베이스에 쓸 때 첫 번째 솔루션보다 선호됩니다. 이 방법을 사용하면 애플리케이션 서버와 데이터베이스 서버 간의 시간 차이로 인한 불일치(최대 몇 분)의 위험이 줄어듭니다

## 날짜 표시

날짜를 표시 목적으로 문자열로 변환하면 [formatDate](f-formatdate.md) 함수가 사용됩니다.

## XML 문서에서 날짜 변환

Adobe Campaign 데이터베이스에서 가져온 XML 문서에 저장된 날짜는 텍스트 형식입니다. [parseTimeStamp](f-parsetimestamp.md) 함수를 사용하여 변환할 수 있습니다. 일반적으로 [ExecuteQuery](sm-querydef-executequery.md) 메서드에서 반환된 XML 문서와 관련이 있습니다. 예 :

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "get", 
    select: {
      node: {expr: "@lastModified"}
    }, 
    where: {
      condition: {expr: "@id=123456"}
    }
  }}
)

var delivery = query.ExecuteQuery()
var lastModified = parseTimeStamp(delivery.$lastModified)
```

## XML 문서에 날짜 삽입

XML 특성으로 날짜를 작성할지, 문서([Write](sm-session-write.md) 메서드)를 저장할지 또는 리터럴 날짜를 쿼리 식에 삽입할지 여부에따라 날짜가 ISO8601 형식으로 변환되어야 합니다. xtk:shared/nl.js 함수 라이브러리에는 날짜를 NL.XTK.formatDateTime(date) 메서드인 이 형식으로 변환하는 메서드가 있습니다. 라이브러리는 loadLibrary 함수를 사용하여 로드할 수 있습니다.

```javascript
loadLibrary("xtk:shared/nl.js")
```

또는 JSSP(다이내믹 JavaScript 페이지)의 경우 page 지시문 사용:

```xml
<%@ page import="xtk:shared/nl.js" %>
```

경고: 모든 스크립트에 loadLibrary를 사용할 수 없습니다. 예를 들어 이메일 개인화 스크립트에서 JavaScript 함수의 라이브러리를 변경할 수 없습니다. 예 : 이 예제는 리터럴 날짜를 사용하여 쿼리를 구성하는 방법을 보여 줍니다.

```javascript
loadLibrary("xtk:shared/nl.js")
NL.require('/nl/core/shared/xtk.js')
...

var date = ...

var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "select", 
    select: {
      node: {expr: "@id"}
    }, 
    where: {
      condition: {expr: "@lastModified > #" + NL.XTK.formatDateTime(date) + "#"}
    }
  }})

var result = query.ExecuteQuery()
```
