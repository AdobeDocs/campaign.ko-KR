# nodeType

노드 유형.

```text
nodeType
```

## 비고

가능한 값:

* 엘레망
* 2 속성
* 3개 텍스트
* 4 CDATA
* 5 엔티티 참조
* 6 엔티티
* 7 처리 명령
* 8 댓글
* 9 문서
* 10 문서 유형
* 11 문서 단편
* 12 표기법

## 기능

**클래스의 속성:** [DOMNode](c-domnode.md)

**읽기 전용:**

예

* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
