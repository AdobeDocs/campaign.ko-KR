# mkdir

현재 [File](c-file.md) 개체의 경로를 사용하여 디렉터리를 만듭니다.

```text
mkdir ()
```

## 매개변수

없음.

## 반환 값

없음.

## 비고

또한 필요한 경우 중간 디렉토리를 만듭니다. 오류가 발생한 경우 예외가 발생합니다.

## 기능

**클래스의 메서드:** [파일](c-file.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
