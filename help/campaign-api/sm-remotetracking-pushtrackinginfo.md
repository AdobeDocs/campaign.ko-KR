# 푸시 추적 정보

게재와 관련된 모든 정보를 원격 서버에 업로드할 수 있습니다.

```text
PushTrackingInfo ( String instance, String dbId, String jobId, XML document )
```

## 매개변수

**인스턴스** 인스턴스 이름

게재를 수행하는 고객의 **dbId** 데이터베이스 식별자

**jobId** 배달 ID.

**문서** 이 게재에 대한 추적 정보가 포함된 문서

## 반환 값

없음.
