# JavaScript 예외

기본적으로 오류가 발생하면 실행 중인 스크립트가 중단됩니다. 그러나 버전 4.05 이상에서는 오류를 캡처하고 처리하여 스크립트를 계속 처리할 수 있습니다.

Adobe Campaign에서 발생한 예외는 오류 코드(`Number` 유형)입니다.

## 예제

이 예제에서는 잘못된 주소에서 웹 페이지를 복구하고 [getUrl()](f-geturl.md) 함수에서 예외를 발생시킵니다.

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
