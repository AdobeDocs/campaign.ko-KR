# transitionByName

지정된 이름에 해당하는 전환을 반환합니다.

```text
transitionByName (name)
```

## 매개변수

**이름** 전환 이름입니다.

## 반환 값

매개 변수로 전달된 이름을 가진 전환입니다. 활동에 이 이름을 가진 전환이 없는 경우 null입니다.
