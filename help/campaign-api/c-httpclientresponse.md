# HttpClientResponse(클래스)

HTTP 쿼리에 대한 응답을 나타내는 개체입니다.

`response` 속성으로 HTTP 쿼리를 실행한 후에만 가져올 수 있습니다.

## 속성

| 속성 | 설명 |
| --- | --- |
| [본문](p-httpclientresponse-body.md) | MemoryBuffer 개체 형식의 HTTP 응답 본문입니다. |
| [코드](p-httpclientresponse-code.md) | JavaScript 정수 형식의 HTTP 응답 반환 코드. |
| [codePage](p-httpclientresponse-codepage.md) | 응답의 codePage 값입니다. HTTP 응답 본문을 디코딩하는 데 사용됩니다. |
| [헤더](p-httpclientresponse-header.md) | 모든 HTTP 헤더를 포함하는 객체입니다. |
| [헤더](p-httpclientresponse-headers.md) | 이름별로 그룹화된 HTTP 응답에 대한 헤더 목록입니다. |
| [메시지](p-httpclientresponse-message.md) | HTTP 응답이 전달하는 메시지입니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
