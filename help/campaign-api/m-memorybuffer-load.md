# 로드

파일의 내용을 버퍼에 로드합니다.

```text
load (filename)
```

## 매개변수

**파일 이름** 로드할 파일의 이름입니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [MemoryBuffer](c-memorybuffer.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
