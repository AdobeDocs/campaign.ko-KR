# getRemoteAddr

요청을 보낸 클라이언트 또는 마지막 프록시의 IP 주소를 반환합니다.

```text
getRemoteAddr ()
```

## 매개변수

없음.

## 반환 값

쿼리를 보낸 클라이언트의 IP 주소를 포함하는 문자열입니다.

## 기능

**클래스의 메서드:** [HttpServletRequest](c-httpservletrequest.md)

**다음 위치에서 사용 가능:**

* JSSP
* 웹 앱
