# hasAttribute

속성의 존재를 테스트합니다.

```text
hasAttribute (name)
```

## 매개변수

**이름** 특성 이름입니다.

## 반환 값

속성이 있으면 true이고, 그렇지 않으면 false입니다.

## 기능

**클래스의 메서드:** [DOMElement](c-domelement.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
