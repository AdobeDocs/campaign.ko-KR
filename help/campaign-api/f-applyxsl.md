# applyXsl

XSL 스타일 시트를 사용하여 XML 문서를 변환합니다.

```text
applyXsl (xslEntity, xml)
```

## 매개변수

**xslEntity** 데이터베이스에 저장된 XSL 스타일 시트의 이름입니다.

**xml** 변환할 XML 문서가 포함된 XML 문서 또는 문자열입니다.

## 반환 값

변환 후 문자열 형식의 XML 문서입니다.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
