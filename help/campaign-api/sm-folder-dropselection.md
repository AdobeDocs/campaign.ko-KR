# DropSelection

```text
DropSelection ( String schema, String entityFolder, XML selectionList, Number folderDestId )
```

## 매개변수

**스키마** 선택 스키마 ID

대상 폴더의 **entityFolder** ID

이동할 **selectionList** 선택

**folderDestId** 대상 폴더

## 반환 값

없음.
