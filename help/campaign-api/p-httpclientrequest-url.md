# URL

원격 서버의 주소입니다.

```text
url
```

## 비고

읽기/쓰기 모드의 속성입니다. 예:

```javascript
var http = new HttpClientRequest()
http.url = "http://www.adobe.net"
```

## 기능

**클래스의 속성:** [HttpClientRequest](c-httpclientrequest.md)

**읽기 전용:**

아니요

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
