# E4X 마이그레이션 안내서

JavaScript에서 XML의 기본 지원을 위한 E4X 확장은 Mozilla에 의해 점진적으로 중단됩니다. Adobe Campaign은 이 확장을 많이 사용했으므로 대체 솔루션으로 마이그레이션할 준비를 하고 있습니다.

이 안내서의 목적은 대체 솔루션을 설명하여 기존 구성을 마이그레이션하거나 새 구성을 개발하는 데 있습니다.

이전 시스템과 새 시스템이 공존하는 경우, Adobe Campaign의 현재 버전은 항상 E4X와 호환되지만 새 구성은 E4X 확장을 사용하여 개발해서는 안 됩니다.

미리 알림: E4X는 소스 프로그램에서 직접 작성할 수 있는 JavaScript xml 유형을 추가합니다.

```text
var doc = <xml> ... </xml>
```

또는 문자열에서

```text
var doc = new XML ("<xml>...</xml>")
```

그런 다음 특정 API로 조작할 수 있습니다.

```text
element.@id element.where
```

## XML 유형

네이티브 &quot;xml&quot; 형식은 DOM API로 대체되며, [DOMDocument](c-domdocument.md) , [DOMElement](c-domelement.md) , [DOMNode](c-domnode.md) 형식... 다음은 가장 일반적인 작업과 동일합니다.

> **E4X:**
>
> ```javascript
> anElement.@id
> ```
>
> **DOM:**
>
> ```javascript
> anElement.$id
> ```
>
> **E4X:**
>
> ```javascript
> anElement.@["recipient-id"]
> ```
>
> **DOM:**
>
> ```javascript
> anElement["$recipient-id"]
> ```
>
> **E4X:**
>
> ```javascript
> anElement.childElement
> ```
>
> **DOM:**
>
> ```javascript
> anElement.getElements("childElement")
> ```
>
> 또는
>
> ```javascript
> anElement.getFirstElement("childElement")
> ```

JavaScript의 XML 문서를 교체해야 합니다. 이 문서를 네이티브 함수 또는 매개 변수의 XML 문서를 전달하는 SOAP 호출에 사용하려는 경우 JXON을 직접 전달할 수 있습니다. 그러면 자동으로 XML 문서(DOMDocument)로 변환됩니다. 그렇지 않으면 항상 JXON 개체를 통해 전달할 수 있지만 [DOMDocument.fromJXON](m-domdocument-fromjxon.md) 함수를 사용하는 명시적 변환이 필요합니다.

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
{schema: "xtk:workflow", operation: "select",
  select: { node: {expr: "@internalName"} } 
}
})
```

XML과 JXON 구문 간의 동등한 권한의 예:

> **E4X:**
>
> ```xml
>                             <queryDef schema="nms:delivery" operation="get">
>     <select>
>         <node expr="@created"/>
>         <node expr="@lastModified"/>
>     </select>
>     <where>
>         <condition expr="@id=123456"/>
>     </where>
> </queryDef>
> ```
>
> **JXON:**
>
> ```javascript
>                             {queryDef: {schema: "nms:delivery", operation: "get", 
>     select: {
>         node: [
>             {expr: "@created"}, 
>             {expr: "@lastModified"}]
>         }, 
>     where: {
>         condition: {expr: "@id=123456"}
>     }
> }}
> ```

JXON 구문에 대한 자세한 내용은 XML 사용 페이지를 참조하십시오.

## SOAP 호출

이러한 SOAP 메서드는 NLWS 개체 속성을 실행해야 합니다. 스키마의 JavaScript ID는 네임스페이스와 대문자로 시작하는 이름에서 만들어집니다. 예를 들어 nms:delivery 스키마의 JS ID는 nmsDelivery입니다.

> **이전:**
>
> ```javascript
> nms.delivery.Play(deliveryId);
> ```
>
> **새로 만들기:**
>
> ```javascript
> NLWS.nmsDelivery.Play(deliveryId);
> ```

## SOAP JavaScript 메서드

매개 변수가 E4X 형식이 아닌 DOM 형식으로 되어 있는 XML 문서를 수신하려면 dom=&quot;true&quot; 속성을 스키마에 추가해야 합니다.

## 여러 줄 문자열

XML을 사용하여 여러 줄 문자열을 만들려면 줄 끝을 추가하지 않고 문자열 연결로 대체해야 합니다. \\n

> **이전:**
>
> ```xml
> <str>line 1
> line 2
> line 3
> </str>.toString()
> ```
>
> **새로 만들기:**
>
> ```javascript
> "line 1\n" +
> "line 2\n" +
> "line 3\n"
> ```
