# sendError

매개 변수로 전달된 오류 코드를 사용하여 오류 응답을 반환합니다.

```text
sendError (errorCode)
```

## 매개변수

**errorCode** HTTP 오류 코드입니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [HttpServletResponse](c-httpservletresponse.md)

**다음 위치에서 사용 가능:**

* JSSP
* 웹 앱
