# DOMAttr(클래스)

속성 유형 노드입니다.

## 속성

| 속성 | 설명 |
| --- | --- |
| [isId](p-domattr-isid.md) | 속성이 ID 유형인 경우 true입니다. |
| [이름](p-domattr-name.md) | 속성 이름. |
| [ownerElement](p-domattr-ownerelement.md) | 이 특성을 가진 요소 또는 null. |
| [지정](p-domattr-specified.md) | 값이 명시적으로 지정된 경우 true입니다(기본적으로 암시적 값이 아님). |
| [값](p-domattr-value.md) | 속성 텍스트 값입니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
