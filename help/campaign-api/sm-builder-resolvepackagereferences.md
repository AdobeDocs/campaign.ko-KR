# 패키지 참조 확인

패키지의 종속성 해결

```text
[ XML patchedPackage, Number warningNb ] = ResolvePackageReferences ( XML parameters )
```

## 매개변수

가져올 패키지가 포함된 **매개 변수** XML 요소입니다.

## 반환 값

**patchedPackage** 처리된 패키지.

**warningNb** 생성된 경고 수입니다.
