# Cookie(클래스)

서블릿과 웹 브라우저가 교환한 쿠키를 나타냅니다.

## 속성

| 속성 | 설명 |
| --- | --- |
| [이름](p-cookie-name.md) | 쿠키 이름. |
| [댓글](p-cookie-comment.md) | 쿠키의 기능을 설명하는 댓글, 정의되지 않은 경우 null. |
| [도메인](p-cookie-domain.md) | 쿠키의 도메인 이름입니다. |
| [maxAge](p-cookie-maxage.md) | 쿠키 수명(초)입니다. |
| [경로](p-cookie-path.md) | 웹 브라우저가 쿠키를 전달하는 데 기준이 되는 경로입니다. |
| [보안](p-cookie-secure.md) | 쿠키가 보안 프로토콜을 통해서만 전달될 수 있는 경우 true입니다. |
| [값](p-cookie-value.md) | 쿠키 값. |
| [버전](p-cookie-version.md) | 쿠키가 호환되는 프로토콜 버전입니다. |

## 기능

**다음 위치에서 사용 가능:**

* JSSP
* 웹 앱
