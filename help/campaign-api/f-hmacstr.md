# hmacStr

문자 문자열의 MD5, SHA-1 또는 SHA-256 해시를 계산합니다. 이 문자열은 계산 전에 자동으로 UTF-8로 인코딩됩니다.

```text
hmacStr (string [, key ] [, algo ])
```

## 매개변수

**string** 해시를 계산할 문자열입니다.

문자열 형식의 **키** 키입니다. 자동으로 UTF-8로 변환됩니다. 키가 누락된 경우 서버는 인스턴스에 종속되고 이 인스턴스에서만 유효한 키를 사용합니다.

**algo** 사용할 해시 유형입니다. 가능한 값은 &quot;MD5&quot;, &quot;SHA1&quot; 또는 &quot;SHA256&quot;입니다. 대소문자가 무시되므로 소문자나 대문자로 값을 입력할 수 있습니다. 매개 변수를 지정하지 않으면 기본적으로 &quot;SHA1&quot; 값이 선택됩니다.

## 반환 값

매개 변수로 전달된 문자열의 MD5, SHA-1 또는 SHA-256 해시(선택한 해시 유형에 따라 다름)입니다.

## 비고

MD5 및 SHA-1 유형의 경우 키는 UTF-8로 변환된 후 최대 64자(512비트)일 수 있습니다. SHA-256 유형의 경우 키는 UTF-8로 변환된 후 최대 32자(256비트)가 될 수 있습니다.
