# 엔티티(클래스)

주어진 스키마에 대한 데이터베이스의 엔티티를 나타냅니다.

이러한 개체는 직접 인스턴스화할 수 없습니다. create(), get() 또는 load() 메서드를 사용해야 합니다.

## 방법

| 방법 | 설명 |
| --- | --- |
| [저장](m-entity-save.md) | 데이터베이스에 엔티티를 저장합니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
