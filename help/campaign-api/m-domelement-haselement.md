# hasElement

주어진 기준을 확인하여 요소에 하위 요소가 있는지 테스트합니다.

```text
hasElement (tagName [, attrName ] [, attrValue ])
```

## 매개변수

**tagName** 검색된 요소의 이름입니다.

**attrName** 지정된 값을 확인해야 하는 특성의 이름입니다.

**attrValue** 특성 값입니다.

## 반환 값

지정된 데이터를 확인하여 요소에 하위가 있으면 true이고, 그렇지 않으면 false입니다.

## 기능

**클래스의 메서드:** [DOMElement](c-domelement.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
