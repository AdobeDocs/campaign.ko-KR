# SysEnum

이 컨트롤을 사용하면 시스템 열거형에서 값을 선택할 수 있습니다.

![SysEnum 컨트롤](assets/sysenum.1eccf324.png)

## 속성

**backColor - string** 배경색(btnshadow, white).

**border - string** 컨트롤 윤곽선 스타일(단색, 이중, 인세트, 시작, 없음)을 변경합니다.

**defaultIfInvalid - 문자열** 값이 잘못된 경우 사용할 값입니다.

**enum - 사용할 문자열** 열거형입니다.

**font-size - integer** 글꼴 크기를 변경합니다.

**레이블 - 문자열** 관련 레이블입니다.

**noInvalidErr - 부울** 값이 잘못된 경우 오류를 표시하지 않습니다.

**nolabel - 부울** 연결된 레이블을 숨깁니다.

**읽기 전용 - 부울** 컨트롤을 읽기 전용으로 강제 실행합니다.

**필수 - 부울** 필드는 필수입니다.

**serialize - boolean** 선택한 마지막 값을 저장합니다.

**useDesc - 부울** 레이블이 아닌 설명을 표시합니다.

**xpathEnum - xpath** 열거형에 열거형 속성이 아닌 이 XPath에서 참조하는 값을 사용합니다.
