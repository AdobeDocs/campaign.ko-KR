# 수면

지정된 시간 동안 스크립트를 일시 중단합니다.

```text
sleep (delay)
```

## 매개변수

**지연** 시간(밀리초)입니다.

## 반환 값

없음.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
