# textContent

노드의 텍스트 콘텐츠입니다. 값은 노드 유형에 따라 다릅니다.

```text
textContent
```

## 비고

이 속성은 읽기 및 쓰기 권한으로 액세스할 수 있습니다.

**클래스의 속성:** [DOMNode](c-domnode.md)
