# lookupNamespaceURI

지정된 접두사에 연결된 네임스페이스의 URI를 검색했습니다.

```text
lookupNamespaceURI (prefix)
```

## 매개변수

**접두사** 접두사입니다.

## 반환 값

네임스페이스의 URI 또는 찾을 수 없는 경우 빈 문자열.

## 기능

**클래스의 메서드:** [DOMNode](c-domnode.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
