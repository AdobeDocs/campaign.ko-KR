# resetServiceMobileAppsCustomHook

동일한 서비스의 모든 모바일 앱에 대해 웹 서비스 추가 매개변수를 삭제합니다.

```text
XML serviceOut = resetServiceMobileAppsCustomHook ( XML serviceContent )
```

## 매개변수

현재 서비스 노드의 **serviceContent** 콘텐츠

## 반환 값

처리 후 서비스 노드의 **serviceOut** 콘텐츠

**스키마:** [nms:mobileApp](s-nms-mobileapp.md)
