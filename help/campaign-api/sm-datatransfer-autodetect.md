# 자동 감지

자동 감지 시작 및 파일의 첫 번째 라인 반환

```text
XML result = AutoDetect ( String fileName, Number codepage )
```

## 매개변수

**fileName** 파일 이름

**codepage** 문자 인코딩

## 반환 값

**result** 파일의 첫 번째 줄을 반환합니다.
