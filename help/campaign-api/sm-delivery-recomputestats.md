# RecomputeStats

게재 액션용 게재 및 추적 통계를 다시 계산합니다.

```text
RecomputeStats ( Number deliveryId, Number dirtyFlags )
```

## 매개변수

**deliveryId** 게재 식별자

다시 계산할 항목을 설명하는 **dirtyFlags** 비트 필드(&#39;nms:delivery:dirtyFlags&#39; 열거 참조).

## 반환 값

없음.
