# insertData

특정 위치에 있는 텍스트에 문자열을 삽입합니다.

```text
insertData (offset, arg)
```

## 매개변수

**offset** 삽입 위치(첫 번째 문자의 경우 0).

삽입할 **arg** 문자 문자열입니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [DOMCcharacterData](c-domcharacterdata.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
