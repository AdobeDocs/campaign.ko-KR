# instanceUploadDir

스크립트가 실행되는 인스턴스에 대한 &#39;업로드&#39; 디렉터리의 전체 경로입니다.

```text
instanceUploadDir
```

## 비고

반환된 값은 서버 매개 변수에서 업로드 디렉터리의 가능한 오버로드를 고려합니다.
