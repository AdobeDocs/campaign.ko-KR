# 하위 노드

자식 노드 목록을 표 형식으로 반환합니다.

```text
childNodes
```

## 비고

이 속성은 각 액세스에 대해 새 테이블을 만듭니다. 따라서 속성을 여러 번 쿼리하는 것보다 테이블을 로컬 변수에 유지하는 것이 좋습니다.

## 기능

**클래스의 속성:** [DOMNode](c-domnode.md)
