# logError

워크플로우 인스턴스의 로그에 오류 메시지를 추가하고 스크립트 실행을 중단합니다.

```text
logError (message)
```

## 매개변수

**메시지** 로그에 추가할 메시지입니다.

## 반환 값

없음.

## 비고

진행 중인 작업은 오류가 발생한 것처럼 작동합니다. 오류에 플래그가 지정되고 워크플로가 일시 중단됩니다. 따라서 이 함수는 워크플로우에서 명시적으로 오류를 일으키고 일시 중단하는 데 유용합니다.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
