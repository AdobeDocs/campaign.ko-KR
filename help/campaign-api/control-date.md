# 날짜

날짜 유형 컨트롤을 사용하면 날짜를 입력할 수 있습니다.

![날짜 컨트롤](assets/date.925e5185.png)

## 속성

**backColor - string** 배경색(btnshadow, white).

**border - string** 제어하는 동안 테두리 스타일을 변경합니다(단색, 이중, 인세트, 시작, 없음).

**font-size - integer** 글꼴 크기를 변경합니다.

**레이블 - 문자열** 관련 레이블입니다.

**nolabel - 부울** 연결된 레이블을 숨깁니다.

**읽기 전용 - 부울** 컨트롤을 읽기 전용으로 강제 실행합니다.

**필수 - 부울** 필드는 필수입니다.

## 비고

이 컨트롤을 사용하여 날짜/시간 유형 필드를 참조하여 날짜 부분만 편집할 수 있습니다. 시간 부분은 0으로 재설정됩니다.
