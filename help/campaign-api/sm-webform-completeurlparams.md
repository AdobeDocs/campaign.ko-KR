# CompleteURLParams

성공 URL 작성

```text
String result = CompleteURLParams ( String formName, String xpathParams, XML recipient )
```

## 매개변수

**formName** 양식 이름

반환할 XPath를 쉼표로 구분한 **xpathParams** 목록

**받는 사람** 받는 사람 데이터

## 반환 값

**result** URL에 대한 매개 변수 반환
