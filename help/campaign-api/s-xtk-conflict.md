# 충돌

> 경고: 이 함수는 온-프레미스 환경에서 사용할 수 있습니다.

충돌 엔티티의 임시 스토리지.

## 방법

| 방법 | 설명 |
| --- | --- |
| [AcceptCus](sm-conflict-acceptcus.md) | 현재 버전을 유지합니다. |
| [AcceptNew](sm-conflict-acceptnew.md) | 새 버전을 현재 버전으로 허용합니다. |
| [해결됨](sm-conflict-setresolved.md) | 더 이상 충돌이 없는 엔터티를 선언합니다. |

## 제네릭 메서드

| 방법 | 설명 |
| --- | --- |
| [만들기](f-create.md) | 지정된 스키마에 해당하는 새 엔티티를 만듭니다. |
| [로드](f-load.md) | 주어진 스키마 및 키에 해당하는 엔티티를 로드하고 반환합니다. |
| [저장](m-entity-save.md) | 데이터베이스에 엔티티를 저장합니다. |
