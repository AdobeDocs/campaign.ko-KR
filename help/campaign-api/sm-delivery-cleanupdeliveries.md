# CleanupDelivery

중간 소싱 서버에서 특정 게재가 삭제되도록 지정합니다.

```text
CleanupDeliveries ( String deliveryId )
```

## 매개변수

**deliveryId** 전송 데이터베이스의 게재 식별자 목록(쉼표로 구분)

## 반환 값

없음.
