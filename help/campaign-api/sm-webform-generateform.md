# GenerateForm

메일 또는 웹 모드에서 양식을 생성합니다.

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## 매개변수

**formName** 양식 이름

**mailMode** 메일 형식 생성

## 반환 값

**result** 양식에 XSL을 적용한 결과

**스키마:** [nms:webForm](s-nms-webform.md)
