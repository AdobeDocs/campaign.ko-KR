# 체계

사용된 프로토콜 이름(HTTP, HTTPS 등)을 반환합니다. 을 클릭하여 이 페이지에 액세스합니다.

```text
scheme
```

## 비고

예: 다음 URL의 체계:

```javascript
      http://adobe.com:8080/nms/test.jst?id=1234&param=dummy#aFragment
```

는 다음 문자열을 반환합니다.

```javascript
http
```
