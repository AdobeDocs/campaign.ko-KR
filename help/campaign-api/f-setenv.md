# 세트 환경

>[!WARNING]
>
>이 함수는 온-프레미스 환경에서 사용할 수 있습니다.

>[!NOTE]
>
>**XtkSecurity\_Disable\_GetSetEnv** 옵션을 **true**(으)로 전달하여 이 함수를 비활성화할 수 있습니다.

환경 변수의 값을 설정합니다.

```text
setEnv (name, value)
```

## 매개변수

환경 변수의 **이름** 이름입니다.

**값** 환경 변수에 대한 새 값입니다.

## 반환 값

변수의 새 값입니다.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
