# 채우기 단계

동일한 수의 빈에 대해 컷오프를 자동으로 생성합니다.

```text
XML samplingSteps = FillSteps ( String schema, String expr, Number classCount )
```

## 매개변수

분석의 **스키마** 루트 스키마

**expr** Source 식

**classCount** 생성할 빈 수

## 반환 값

**samplingSteps** 단계 목록
