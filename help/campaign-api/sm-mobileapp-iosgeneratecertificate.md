# iOSGenerateCertificate

제공된 iOS 인증서를 base64에서 인코딩합니다.

```text
String return = iOSGenerateCertificate ( String fileName, String uuid )
```

## 매개변수

**fileName** 파일 이름

**uuid** 응용 프로그램 UUID

## 반환 값

**반환** 인증서의 base64 버전
