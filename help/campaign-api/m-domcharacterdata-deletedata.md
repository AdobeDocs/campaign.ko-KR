# deleteData

텍스트 일부를 삭제합니다.

```text
deleteData (offset, count)
```

## 매개변수

**offset** 삭제할 첫 번째 문자의 위치(첫 번째 문자의 경우 0)입니다.

**count** 삭제할 문자 수입니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [DOMCcharacterData](c-domcharacterdata.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
