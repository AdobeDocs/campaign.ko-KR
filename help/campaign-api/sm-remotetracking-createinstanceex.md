# CreateInstanceEx

추적 인스턴스 생성에 사용됨

```text
CreateInstanceEx ( String instanceName, String hosts, String dbId, String cryptedPwd, String lang, String imsOrgId )
```

## 매개변수

**instanceName** 만들 인스턴스의 이름

인스턴스와 연결된 **호스트** DNS 마스크

게재를 수행하는 고객의 **dbId** 데이터베이스 식별자

추적에 사용되는 **cryptedPwd** 암호화된 암호

**lang** 인스턴스 언어

**imsOrgId** IMS 조직 ID

## 반환 값

없음.
