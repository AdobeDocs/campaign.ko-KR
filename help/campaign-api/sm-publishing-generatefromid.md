# GenerateFromId

폴더의 식별자가 참조하는 콘텐츠를 생성하고 게시합니다.

```text
String outputFiles = GenerateFromId ( String id, String publishingDir )
```

## 매개변수

**id** 콘텐츠 식별자

**publishingDir** 게시 폴더

## 반환 값

**outputFiles** 생성된 파일 목록
