# getFirstElement

지정된 조건을 확인하여 첫 번째 하위 요소를 반환합니다.

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## 매개변수

**tagName** 검색된 요소의 이름입니다.

**attrName** 지정된 값을 확인해야 하는 특성의 이름입니다.

**attrValue** 특성 값입니다.

## 반환 값

지정된 기준 또는 null을 확인하는 첫 번째 요소입니다.

## 기능

**클래스의 메서드:** [DOMElement](c-domelement.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
