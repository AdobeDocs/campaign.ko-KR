# 테이블 목록 작성

테이블 이름 목록을 가져옵니다.

```text
XML tableList = BuildTableList ( String dataSource, String tablePattern )
```

## 매개변수

데이터 원본의 **dataSource** ID

테이블 이름에 대한 **tablePattern** 마스크

## 반환 값

기존 테이블의 **tableList** 목록
