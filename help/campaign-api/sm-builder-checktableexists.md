# 검사 테이블 존재

데이터베이스에 테이블이 존재하는지 확인합니다.

```text
Boolean exists = CheckTableExists ( String dataSource, String tableName )
```

## 매개변수

**dataSource** 데이터 원본

**tableName** 테이블 이름

## 반환 값

**존재함** 결과
