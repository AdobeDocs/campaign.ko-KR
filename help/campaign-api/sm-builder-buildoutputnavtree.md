# BuildOutputNavTree

데이터베이스에 있는 탐색 트리 정의를 매개변수에 지정된 탐색 트리 정의와 병합합니다.

```text
XML navtree = BuildOutputNavTree ( XML navtreeSource, Boolean save )
```

## 매개변수

**navtreeSource** Source 탐색 트리

**저장** 결과 저장

## 반환 값

**navtree** 병합 결과
