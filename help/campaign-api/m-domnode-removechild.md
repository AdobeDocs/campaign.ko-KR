# removeChild

노드를 삭제합니다.

```text
removeChild (oldChild)
```

## 매개변수

삭제할 **oldChild** 노드입니다.

## 반환 값

노드가 삭제되었습니다.

## 기능

**클래스의 메서드:** [DOMNode](c-domnode.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
