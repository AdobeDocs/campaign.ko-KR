# createEntityReference

새 엔티티 참조를 만듭니다.

```text
createEntityReference (name)
```

## 매개변수

참조된 엔터티의 **이름** 이름입니다.

## 반환 값

[entity](c-domnode.md)이(가) 만들어졌습니다.

## 기능

**클래스의 메서드:** [DOMDocument](c-domdocument.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
