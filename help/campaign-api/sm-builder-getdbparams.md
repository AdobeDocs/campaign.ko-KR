# GetDbParams

데이터 소스의 현재 매개 변수를 검색합니다.

```text
[ XML dbcnx, XML dbParameters ] = GetDbParams ()
```

## 매개변수

없음.

## 반환 값

**dbcnx** 데이터 원본 정의

**dbParameters** 네임스페이스 및 테이블스페이스를 업데이트합니다.
