# getParameter

쿼리 매개 변수의 값을 반환합니다.

```text
getParameter (name)
```

## 매개변수

**이름** 매개 변수 이름입니다.

## 반환 값

요청한 매개 변수의 값입니다.

## 기능

**클래스의 메서드:** [HttpServletRequest](c-httpservletrequest.md)

**다음 위치에서 사용 가능:**

* JSSP
* 웹 앱
