# DOMDocument(클래스)

XML 문서.

## 방법

| 방법 | 설명 |
| --- | --- |
| [DOMDocument](m-domdocument-domdocument.md) | 새 문서를 만듭니다. |
| [fromXMLString](m-domdocument-fromxmlstring.md) | XML 문자 문자열로 새 문서를 만듭니다. |
| [fromJXON](m-domdocument-fromjxon.md) | JXON 객체에서 새 문서를 만듭니다. |
| [로드](m-domdocument-load.md) | XML 파일에서 새 문서를 만듭니다. |
| [toXMLString](m-domdocument-toxmlstring.md) | XML 문서를 문자열로 변환합니다. |
| [createElement](m-domdocument-createelement.md) | 새 요소를 만듭니다. |
| [createElementNS](m-domdocument-createelementns.md) | 지정된 이름과 네임스페이스로 새 요소를 만듭니다. |
| [createTextNode](m-domdocument-createtextnode.md) | 새 텍스트 유형 노드를 만듭니다. |
| [createComment](m-domdocument-createcomment.md) | 새 주석 유형 노드를 만듭니다. |
| [createCDATASsection](m-domdocument-createcdatasection.md) | 새 CDATA 유형 노드를 만듭니다. |
| [createProcessingInstruction](m-domdocument-createprocessinginstruction.md) | 새 처리 명령을 만듭니다. |
| [createEntityReference](m-domdocument-createentityreference.md) | 새 엔티티 참조를 만듭니다. |
| [getElementsByTagName](m-domdocument-getelementsbytagname.md) | 지정한 이름을 가진 모든 요소의 목록을 반환합니다. |
| [getElementsByTagNameNS](m-domdocument-getelementsbytagnamens.md) | 지정된 이름과 네임스페이스가 있는 모든 문서 요소의 목록을 반환합니다. |
| [getElementById](m-domdocument-getelementbyid.md) | 지정된 ID로 요소를 반환합니다. |
| [importNode](m-domdocument-importnode.md) | 다른 문서에서 노드 복사본을 만듭니다. |
| [normalizeDocument](m-domdocument-normalizedocument.md) | 문서를 표준화합니다. 엔티티 참조가 대체되고 인접한 텍스트 노드가 융합됩니다. |
| [renameNode](m-domdocument-renamenode.md) | 요소 또는 속성의 이름을 변경합니다. |

## 속성

| 속성 | 설명 |
| --- | --- |
| [루트](p-domdocument-root.md) | 문서의 루트 요소입니다. 이 속성은 [documentElement](p-domdocument-documentelement.md) 과(와) 동의어입니다. |
| [documentElement](p-domdocument-documentelement.md) | 문서의 루트 요소입니다. |
| [documentURI](p-domdocument-documenturi.md) | 문서 네임스페이스 URI. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
