# 파일

파일과 연결된 새 개체를 만듭니다.

```text
File (filename)
```

## 매개변수

**파일 이름** 읽거나 만들 파일의 이름입니다.

## 반환 값

없음.

## 비고

예:

```javascript
var f = new File("/tmp/file.txt")
```

## 기능

**클래스의 메서드:** [파일](c-file.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
