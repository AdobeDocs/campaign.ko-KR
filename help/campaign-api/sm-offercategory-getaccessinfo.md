# Get액세스 정보

익명 모드의 상속된 속성을 반환합니다.

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## 매개변수

**categoryId** 범주 ID

## 반환 값

**익명** 범주 오퍼의 익명 여부를 지정합니다.

**parentAnonymous** 상위 범주 오퍼의 익명 여부를 지정합니다.
