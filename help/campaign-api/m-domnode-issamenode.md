# isSameNode

지정된 참조가 동일한 노드를 나타내는지 테스트합니다.

```text
isSameNode ()
```

## 매개변수

없음.

## 반환 값

두 참조가 동일한 노드를 나타내는 경우 true이고, 그렇지 않으면 false입니다.

## 비고

이 메서드는 두 참조를 비교하는 데 사용해야 합니다. JavaScript 연산자 == 및 ===은 사용할 수 없습니다.

## 기능

**클래스의 메서드:** [DOMNode](c-domnode.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
