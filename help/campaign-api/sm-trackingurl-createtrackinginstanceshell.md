# CreateTrackingInstanceShell

리디렉션 서버에서 추적 인스턴스 만들기 또는 구성

```text
CreateTrackingInstanceShell ( String internalPwd, String serverUrlList, String instanceName, String cryptedPassword, String host )
```

## 매개변수

**internalPwd** 내부 암호

추적 서버의 **serverUrlList** 내부 URL

**instanceName** 만들 인스턴스의 이름

**cryptedPassword** 암호화된 암호

인스턴스와 연결된 **호스트** DNS 마스크

## 반환 값

없음.

**스키마:** [nms:trackingUrl](s-nms-trackingurl.md)
