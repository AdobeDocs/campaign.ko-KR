# get

주어진 스키마 및 키에 해당하는 엔티티를 로드하고 반환합니다.

```text
get ( [key or content ])
```

## 매개변수

**키 또는 콘텐츠** 새 엔터티를 만들거나 시작할 XML 콘텐츠 엔터티의 키에 해당하는 문자열입니다.

## 반환 값

JavaScript 개체 형태로 엔티티를 반환합니다.

## 비고

get은 전역 함수가 아니라 스키마 메서드입니다. 호출하려면 원하는 스키마로 접두사를 지정해야 합니다. 예제:

```javascript
var delivery = NLWS.nmsDelivery.get("12435")
```

이 개체의 속성 및 하위 속성은 언제든지 수정할 수 있습니다. 이 문서는 수정되는 경우 스크립트 실행이 완료되면 자동으로 데이터베이스에 저장됩니다. 작성되지 않은 엔티티가 데이터베이스에 아직 없는 경우 오류가 발생하며 스크립트가 중단됩니다.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
