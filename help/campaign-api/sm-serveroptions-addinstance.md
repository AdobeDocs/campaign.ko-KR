# AddInstance

> 경고: 이 함수는 온-프레미스 환경에서 사용할 수 있습니다.

서버에서 새 인스턴스 선언

```text
AddInstance ( String instanceName, String hosts, String lang )
```

## 매개변수

**instanceName** 만들 인스턴스의 이름

인스턴스와 연결된 **호스트** DNS 마스크

**lang** 인스턴스 언어

## 반환 값

없음.
