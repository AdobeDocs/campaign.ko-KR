# WebPostupload

사용된 스토리지 유형에 따라 (웹 페이지에서) 서버로 업로드한 후 리소스의 스토리지를 완료합니다. 코드 페이지 및 콘텐츠 유형을 복구합니다.

```text
fileRes.WebPostUpload ( XML params )
```

## 매개변수

**params** &#39;작업 영역&#39; 형식 저장소: @formerFileName에 작업 영역의 이전 이름이 포함되어 있습니다. 엔티티를 즉시 저장하려면 다음을 @immediateSave 합니다.

없음.
