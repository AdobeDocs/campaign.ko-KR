# appendChild

하위 폴더 목록의 끝에 노드를 삽입합니다.

```text
appendChild (newChild)
```

## 매개변수

삽입할 **newChild** 노드.

## 반환 값

노드가 삽입되었습니다.

## 기능

**클래스의 메서드:** [DOMNode](c-domnode.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
