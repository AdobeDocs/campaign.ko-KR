# DOMElement(클래스)

요소 유형 노드입니다.

## 방법

| 방법 | 설명 |
| --- | --- |
| [toXMLString](m-domelement-toxmlstring.md) | 요소를 문자 문자열로 변환합니다. |
| [getFirstElement](m-domelement-getfirstelement.md) | 지정된 조건을 확인하여 첫 번째 하위 요소를 반환합니다. |
| [hasElement](m-domelement-haselement.md) | 주어진 기준을 확인하여 요소에 하위 요소가 있는지 테스트합니다. |
| [getValue](m-domelement-getvalue.md) | 지정된 XPath에서 참조하는 노드 값을 반환합니다. |
| [getBooleanValue](m-domelement-getbooleanvalue.md) | 지정된 XPath에서 참조하는 부울 노드 값을 반환합니다. |
| [getDateValue](m-domelement-getdatevalue.md) | 주어진 XPath로 노드 참조의 날짜+시간 유형 값을 반환합니다. |
| [getNumberValue](m-domelement-getnumbervalue.md) | 지정된 XPath에서 참조하는 디지털 노드 값을 반환합니다. |
| [getElements](m-domelement-getelements.md) | 이 요소에 속한 지정된 이름의 자식 요소 목록을 반환합니다. |
| [getAttribute](m-domelement-getattribute.md) | 속성 값을 반환합니다. |
| [setAttribute](m-domelement-setattribute.md) | 속성 값을 변경하거나 새 속성을 만듭니다. |
| [removeAttribute](m-domelement-removeattribute.md) | 속성을 삭제합니다. |
| [getElementsByTagName](m-domelement-getelementsbytagname.md) | 지정한 이름을 가진 모든 자식 요소의 목록을 반환합니다. |
| [getAttributeNS](m-domelement-getattributens.md) | 속성 값을 반환합니다. |
| [setAttributeNS](m-domelement-setattributens.md) | 속성 값을 변경하거나 새 속성을 만듭니다. |
| [removeAttributeNS](m-domelement-removeattributens.md) | 속성을 삭제합니다. |
| [getElementsByTagNameNS](m-domelement-getelementsbytagnamens.md) | 지정한 이름을 가진 모든 자식 요소의 목록을 반환합니다. |
| [hasAttribute](m-domelement-hasattribute.md) | 속성의 존재를 테스트합니다. |
| [hasAttributeNS](m-domelement-hasattributens.md) | 속성의 존재를 테스트합니다. |
| [setIdAttribute](m-domelement-setidattribute.md) | 지정된 특성을 ID 유형 특성으로 선언합니다. |
| [setIdAttributeNS](m-domelement-setidattributens.md) | 지정된 특성을 ID 유형 특성으로 선언합니다. |

## 속성
