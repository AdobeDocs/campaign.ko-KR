# 데이터 보호: 함수를 이스케이프 처리합니다.

Adobe Campaign은 SQL 주입, XSS 공격 등 가장 빈번한 공격으로부터 보호하는 기능 세트를 제공합니다.

이스케이프 기능은 운영자의 감독 하에 사용되어야 하며, Adobe은 개발 중 이러한 기능의 잘못된 사용 또는 미사용에 대한 책임을 지지 않을 수 있습니다.

일반적인 규칙은 다음과 같습니다.

**모든 매개 변수를 이스케이프 처리해야 합니다. 이스케이프에 사용되는 함수는 데이터의 대상 형식에 따라 다릅니다.**

## 간소화된 이스케이프

JSSP에서 Adobe Campaign은 생성된 XML 또는 HTML 엔티티에 사용된 변수를 이스케이프 처리할 수 있도록 하는 &#39;&lt;%=&#39; 태그를 제공합니다. 이 메서드는 보다 편리하며 NL.XML.escape()에 해당합니다. 다음 예에서는 태그를 사용하여 매개 변수를 이스케이프 처리하는 방법을 보여 줍니다.

```xml
<li>
<%= strRecipientList %>
</li>
```

## 고급 이스케이프:

Adobe Campaign에서는 대상 형식에 따라 매개 변수를 이스케이프 처리할 수 있는 4개의 함수를 제공합니다. 이러한 이스케이프 함수에 액세스하려면 다음 파일의 이름을 각각 지정하십시오.

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* 생성된 XML 또는 HTML 엔티티에서 사용되는 변수를 이스케이프하는 NL.XML.escape(data) 이 함수는 &#39;&lt;%=&#39; 구문과 같습니다. 이 함수는 NL.XML 패키지에 정의되어 있습니다.

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape(data) - SQL 쿼리에 사용할 수 있는 매개 변수를 이스케이프 처리합니다. 이 함수는 간단한 따옴표 사이에 식을 자동으로 배치합니다. 이 함수는 NL.SQL 패키지에 정의되어 있습니다.

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* XTK 표현식에 사용될 매개 변수를 이스케이프하는 NL.XTK.toXTKString(data). 이 함수는 NL.XTK 패키지에서 정의됩니다.

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* 클라이언트측에서 실행된 javascript에 사용된 변수를 이스케이프 처리하는 NL.JS.escape(data). 이 함수는 NL.JS 패키지에 정의되어 있습니다.

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```

경고: Adobe Campaign은 이후 버전에 대해 이러한 기능의 내구성을 보장하지 않습니다.
