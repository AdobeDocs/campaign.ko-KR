# createElementNS

지정된 이름과 네임스페이스로 새 요소를 만듭니다.

```text
createElementNS (namespaceURI, qualifiedName)
```

## 매개변수

**namespaceURI** 네임스페이스 URI.

**qualifiedName** 만들 요소의 정규화된 이름입니다.

## 반환 값

[요소](c-domelement.md)을(를) 만들었습니다.

## 기능

**클래스의 메서드:** [DOMDocument](c-domdocument.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
