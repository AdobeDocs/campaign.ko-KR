# GetDeliveryCustomizationAsModel

선택한 개인화 필드 템플릿을 복사합니다.

```text
XML parentOut = GetDeliveryCustomizationAsModel ( XML selection, XML parentIn )
```

## 매개변수

선택한 템플릿 식별자를 포함하는 **선택** 요소

기존 개인화를 포함하는 **parentIn** 요소

## 반환 값

**parentOut** 새 템플릿이 추가된 요소를 반환합니다.
