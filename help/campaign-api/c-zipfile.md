# ZipFile(클래스)

Zip 파일을 조작합니다.

## 방법

| 방법 | 설명 |
| --- | --- |
| [ZipFile](m-zipfile-zipfile.md) | 파일과 연결된 새 Zip 개체를 만듭니다. |
| [dispose](m-zipfile-dispose.md) | 개체에서 사용하는 리소스를 해제합니다. |
| [열기](m-zipfile-open.md) | 기존 아카이브를 로드합니다. |
| [getEntry](m-zipfile-getentry.md) | 아카이브에서 파일 추출 |
| [setEntry](m-zipfile-setentry.md) | 아카이브에 파일을 추가하거나 업데이트합니다. |
| [저장](m-zipfile-save.md) | 아카이브를 저장합니다. |

## 속성

| 속성 | 설명 |
| --- | --- |
| [fileCount](p-zipfile-filecount.md) | 아카이브의 파일 수를 반환합니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
