# toDocument

스키마를 XML 문서 양식으로 변환합니다.

```text
toDocument ()
```

## 매개변수

없음.

## 반환 값

[DOMDocument](c-domdocument.md) 형식 개체입니다.

## 기능

**클래스의 메서드:** [스키마](c-schema.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
