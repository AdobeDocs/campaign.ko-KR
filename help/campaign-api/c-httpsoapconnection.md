# HttpSoapConnection(클래스)

SOAP 서버에 대한 HTTP 연결을 나타냅니다.

## 방법

| 방법 | 설명 |
| --- | --- |
| [HttpSoapConnection](m-httpsoapconnection-httpsoapconnection.md) | SOAP 서버에 대한 HTTP 연결을 만듭니다. |
| [addHeader](m-httpsoapconnection-addheader.md) | HTTP 헤더 추가 |
| [dispose](m-httpsoapconnection-dispose.md) | 개체에서 사용하는 리소스를 해제합니다. |
| [setHeader](m-httpsoapconnection-setheader.md) | HTTP 헤더를 지정합니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
