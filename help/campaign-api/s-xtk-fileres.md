# fileRes

## 방법

| 방법 | 설명 |
| --- | --- |
| [파일 게시](sm-fileres-filepublishing.md) | 전면 서버에 퍼블릭 리소스를 게시합니다. |
| [GetPublicFileResURL](sm-fileres-getpublicfileresurl.md) | 폴더의 URL을 가져옵니다. |
| [GetServerFileName](sm-fileres-getserverfilename.md) | 필요한 경우 업로드 폴더에 복사한 후 서버의 파일 이름을 반환합니다. |
| [GetURL](sm-fileres-geturl.md) | 파일의 URL을 가져옵니다. |
| [PostUpload](sm-fileres-postupload.md) | 정의된 스토리지 유형에 따라 업로드 후 처리. |
| [미리 다운로드](sm-fileres-predownload.md) | 정의된 스토리지 유형에 따라 리소스 다운로드를 준비합니다. |
| [PublishIfNeeded](sm-fileres-publishifneeded.md) | 필요한 경우 미디어 서버에 파일을 복사합니다. |
| [PublishIfNeededFromId](sm-fileres-publishifneededfromid.md) | 필요한 경우 리소스 ID를 사용해 미디어 서버에 파일을 복사합니다. |
| [WebPostUpload](sm-fileres-webpostupload.md) | 사용된 스토리지 유형에 따라 (웹 페이지에서) 서버로 업로드한 후 리소스의 스토리지를 완료합니다. 코드 페이지 및 콘텐츠 유형을 복구합니다. |
