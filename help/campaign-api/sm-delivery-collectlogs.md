# CollectLog

게재 목록의 게재 로그 메시지로 테이블 만들기

```text
CollectLogs ( Number id, XML deliveries, String logTable )
```

## 매개변수

**id** 우선 순위 지정 고유 식별자

고려해야 할 게재 **게재** 목록

모든 로그 메시지를 포함하도록 만들 **logTable** 테이블

## 반환 값

없음.
