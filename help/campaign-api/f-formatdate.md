# formatDate

날짜 형식을 문자열로 지정합니다.

```text
formatDate (date, format [, timeZone ])
```

## 매개변수

**날짜** 변환할 날짜입니다.

**format** 사용할 형식을 설명하는 문자열입니다. 날짜의 여러 부분 서식을 지정하는 데 사용되는 문자는 다음과 같습니다.

* Y - 연도
* M - 월 (1-12)
* B - 월 이름
* D - 해당 월의 일(1-31)
* A - 일 이름
* J - 일 (1-366)
* W - 연간 주
* H - 시간(0-23)
* I - 시간(1-12)
* N - 분(0-59)
* S - 초(0-59)
* P - 오전/오후

이러한 문자 앞에 숫자를 지정할 수 있습니다. A와 B 문자 뒤에 l을 사용하여 단축이 아닌 전체 이름을 사용하거나 i를 사용하여 영어 이름을 사용할 수 있습니다. 예:

* &quot;%4Y/%2M/%2D&quot; => 2000/01/24.
* &quot;%A %D %B %4Y&quot; => 2000년 1월 24일 월요일
* &quot;%Al %D %Bl %4Y&quot; => 2000년 1월 24일 월요일
* &quot;%02H:%02N:%02S&quot;은(는) 두 도형에 시간, 분 및 초를 표시합니다.

**표준 시간대** 표준 시간대에 해당하는 문자 문자열입니다. 가능한 값은 xtk:common:표준 시간대 열거 스키마에 지정되었습니다.

## 반환 값

요청된 형식으로 날짜를 나타내는 문자열.
