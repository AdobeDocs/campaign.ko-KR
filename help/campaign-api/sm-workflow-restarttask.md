# RestartTask

하나 이상의 완료된 작업을 강제로 다시 시작합니다.

```text
RestartTask ( String workflowId, String activityName )
```

## 매개변수

**workflowId** 워크플로의 식별자 또는 내부 이름입니다.

**activityName** 다시 시작할 활동의 이름

## 반환 값

없음.
