# 역방향 링크

요소가 링크인 경우 은 대상 스키마를 통해 역방향 링크를 나타내는 [SchemaNode](c-schemanode.md) 개체를 반환합니다. 그렇지 않으면 속성이 정의되지 않습니다.

```text
reverseLink
```

## 기능

**클래스의 속성:** [SchemaNode](c-schemanode.md)

예
