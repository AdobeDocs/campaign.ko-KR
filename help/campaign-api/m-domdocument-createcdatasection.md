# createCDATASsection

새 CDATA 유형 노드를 만듭니다.

```text
createCDATASection (data)
```

## 매개변수

CDATA 노드에 삽입할 **data** 문자열.

## 반환 값

[CDATA 노드](c-domcharacterdata.md)을(를) 만들었습니다.

## 기능

**클래스의 메서드:** [DOMDocument](c-domdocument.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
