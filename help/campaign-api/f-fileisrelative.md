# fileIsRelative

파일 이름이 상대 이름인지 여부를 지정합니다.

```text
fileIsRelative (fileName)
```

## 매개변수

**fileName** 파일 이름.

## 반환 값

파일 이름의 True는 상대적입니다.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
