# BuildMirror

HTML 미러 페이지를 작성합니다.

```text
[ String content, Number responseCode ] = BuildMirror ( String crypted )
```

## 매개변수

**암호화됨** 메시지 및 게재 부분 식별자의 해독 가능한 암호화

## 반환 값

미러 페이지의 **콘텐츠** 콘텐츠

오류 발생 시 **responseCode** HTTP 응답
