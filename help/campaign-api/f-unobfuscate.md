# 난독화 해제

[난독화](f-obfuscate.md) 덕분에 이전에 난독화된 정수를 난독화하지 않습니다.

```text
unobfuscate (value [, version ])
```

## 매개변수

**값** 난독화할 정수입니다.

**version** 적용할 난독화 버전. 기본적으로 0입니다.

## 반환 값

이전에 [난독화](f-obfuscate.md)하여 난독화된 정수입니다.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
