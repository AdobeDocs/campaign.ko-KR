# 숫자

이 컨트롤을 사용하면 숫자를 입력할 수 있습니다.

![숫자 컨트롤](assets/number.d018cb51.png)

## 속성

**backColor - string** 배경색(btnshadow, white).

**border - string** 제어하는 동안 테두리 스타일을 변경합니다(단색, 이중, 인세트, 시작, 없음).

**digitCount - 정수** 쉼표 뒤에 표시할 그림 수입니다. 기본값은 2입니다.

**font-size - integer** 글꼴 크기를 변경합니다.

**레이블 - 문자열** 관련 레이블입니다.

**nolabel - 부울** 연결된 레이블을 숨깁니다.

**읽기 전용 - 부울** 컨트롤을 읽기 전용으로 강제 실행합니다.

**필수 - 부울** 필드는 필수입니다.

**너비 - 정수** 표시할 문자 수입니다. 기본값은 18이며 000 000 000 000.00과 일치합니다.
