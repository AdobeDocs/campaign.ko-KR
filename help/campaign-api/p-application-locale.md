# 로케일

Local 인스턴스와 일치하는 문자 문자열을 반환합니다.

```text
locale
```

## 비고

로컬은 지역 설정을 정의하는 코드입니다. 언어 코드 다음에 국가 코드가 있고 &#39;-&#39;로 구분되어 있습니다. 값의 예:

* en-US - 영어, 미국
* en-GB - 영어, 영국
* fr-FR - 프랑스어, 프랑스
* de-DE - 독일어, 독일
* es-ES - 스페인어, 스페인
