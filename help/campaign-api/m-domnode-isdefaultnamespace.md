# is기본 네임스페이스

지정된 네임스페이스가 기본값인지 테스트합니다.

```text
isDefaultNamespace (namespaceURI)
```

## 매개변수

**namespaceURI** 네임스페이스 URI.

## 반환 값

namespaceURI가 기본 네임스페이스이면 true이고, 그렇지 않으면 false입니다.

## 기능

**클래스의 메서드:** [DOMNode](c-domnode.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
