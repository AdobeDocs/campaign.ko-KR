# logVerbose

워크플로우 인스턴스의 로그에 정보 메시지를 추가합니다. 이 메시지는 &#39;verbose&#39; 모드에서만 볼 수 있습니다.

```text
logVerbose (message)
```

## 매개변수

**메시지** 로그에 추가할 메시지입니다.

## 반환 값

없음.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
