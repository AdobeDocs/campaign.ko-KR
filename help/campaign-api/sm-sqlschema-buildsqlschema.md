# BuildSqlSchema

매개변수에 지정된 테이블의 실제 구조에서 스키마 코드를 생성합니다.

```text
XML schema = BuildSqlSchema ( String dataSource, String tableName )
```

## 매개변수

데이터 원본의 **dataSource** ID

**tableName** 테이블 이름

## 반환 값

**스키마** 생성된 스키마

## 기능

**스키마:** [xtk:sqlSchema](s-xtk-sqlschema.md)
