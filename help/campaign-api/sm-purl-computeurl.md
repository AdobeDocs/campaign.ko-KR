# ComputeUrl

이 pURL에 액세스하기 위한 URL을 생성합니다.

```text
[ String url, String exampleUrl ] = ComputeUrl ( XML purl )
```

## 매개변수

**purl** 현재 purl입니다.

## 반환 값

**url** URL(기술)

**exampleUrl** 가상 데이터(표시용)가 포함된 URL
