# toXMLString

요소를 문자 문자열로 변환합니다.

```text
toXMLString (format)
```

## 매개변수

**format** XML 문서의 서식을 지정하는 부울입니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [DOMElement](c-domelement.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
