# 샘플

## 정적 메서드

SOAP 메서드에 액세스하려면 스키마를 나타내는 개체에서 메서드를 호출하면 됩니다. 스키마가 &#39;NLWS&#39; 전역 개체입니다. 다음 예제에서는 [xtk:workflow](s-xtk-workflow.md) 스키마의 [PostEvent](sm-workflow-postevent.md) 정적 메서드를 호출합니다.

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## 비정적 메서드

비정적 SOAP 메서드를 사용하려면 먼저 해당 스키마에서 [load](f-load.md) 또는 [create](f-create.md) 메서드를 사용하여 엔터티를 복구해야 합니다. 다음 예제에서는 [xtk:queryDef](s-xtk-querydef.md) 스키마의 [ExecuteQuery](sm-querydef-executequery.md) 메서드를 호출합니다.

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## 제한 사항

로드되는 개체(\*\*)에 데이터가 없으므로 특정 비정적 호출을 사용할 수 없습니다. 예를 들어 [nms:delivery](s-nms-delivery.md)에 대한 특정 호출에 해당합니다.
