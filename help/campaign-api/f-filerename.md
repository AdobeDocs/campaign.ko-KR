# 파일 이름 바꾸기

파일 이름을 변경합니다.

문자 인코딩을 지정하지 않으면 서버 기본값이 사용됩니다.

```text
fileRename (oldname, newname)
```

## 매개변수

**oldname** 이름을 바꿀 파일의 전체 이름입니다.

**newname** 파일의 새 이름입니다.

## 반환 값

없음.

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
