# GetNewIds

데이터베이스의 내부 키 식별자 목록을 수집합니다.

```text
String idList = GetNewIds ( Number count )
```

## 매개변수

**count** 이 메서드가 반환해야 하는 식별자 수

## 반환 값

**idList** 쉼표로 구분된 식별자 목록
