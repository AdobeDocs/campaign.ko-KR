# CreateFromModel

템플릿(해당 내부 이름)에서 게재 생성.

```text
XML delivery = CreateFromModel ( String scenarioName, XML content )
```

## 매개변수

게재 템플릿의 **scenarioName** 내부 이름

템플릿에 추가할 **content** XML 콘텐츠

## 반환 값

**delivery** 생성된 게재 문서를 반환합니다.
