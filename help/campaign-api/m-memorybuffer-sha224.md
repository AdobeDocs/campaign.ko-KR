# sha224

MemoryBuffer 콘텐츠의 SHA-2 224비트 서명을 계산합니다.

```text
sha224 ()
```

## 매개변수

없음.

## 반환 값

SHA-2 224비트 서명의 16진수 표현인 문자열.

## 기능

**클래스의 메서드:** [MemoryBuffer](c-memorybuffer.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
