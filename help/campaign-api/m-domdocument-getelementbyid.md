# getElementById

지정된 ID로 요소를 반환합니다.

```text
getElementById (elementId)
```

## 매개변수

검색된 요소의 **elementId** 식별자입니다. 대/소문자 구분이 중요한 문자열입니다.

## 반환 값

문서에 특정 ID가 있는 요소가 없는 경우 요소 또는 null.

## 기능

**클래스의 메서드:** [DOMDocument](c-domdocument.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
