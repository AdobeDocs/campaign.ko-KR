# setAttributeNS

속성 값을 변경하거나 새 속성을 만듭니다.

```text
setAttributeNS (namespaceURI, qualifiedName, value)
```

## 매개변수

특성 네임스페이스의 **namespaceURI** URI.

**qualifiedName** 특성의 정규화된 이름입니다.

**값** 특성 텍스트 값입니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [DOMElement](c-domelement.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
