# addHeader

응답에 추가 HTTP 헤더를 추가합니다.

```text
addHeader (nom, valeur)
```

## 매개변수

**nom** 추가할 헤더의 이름입니다.

추가된 헤더의 **값**.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [HttpServletResponse](c-httpservletresponse.md)

**다음 위치에서 사용 가능:**

* JSSP
* 웹 앱
