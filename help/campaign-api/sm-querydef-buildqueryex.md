# 빌드 쿼리 표현식

생성된 쿼리 및 형식 문자열을 반환합니다.

```text
[ String sql, String format ] = queryDef.BuildQueryEx () const
```

## 매개변수

없음.

## 반환 값

**sql** 출력 쿼리

**format** 형식 문자열. sqlSelect() JavaScript 함수와 호환됩니다.

## 기능

**스키마:** [xtk:queryDef](s-xtk-querydef.md)

**정적:**

아니요

**Const:**

예

아니요
