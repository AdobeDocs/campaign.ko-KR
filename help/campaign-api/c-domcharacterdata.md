# DOMCcharacterData(클래스)

텍스트만 포함하는 노드입니다. 텍스트 유형 노드이거나 주석일 수 있습니다.

## 방법

| 방법 | 설명 |
| --- | --- |
| [substringData](m-domcharacterdata-substringdata.md) | 텍스트의 일부를 추출합니다. |
| [appendData](m-domcharacterdata-appenddata.md) | 텍스트에 문자열을 추가합니다. |
| [insertData](m-domcharacterdata-insertdata.md) | 특정 위치에 있는 텍스트에 문자열을 삽입합니다. |
| [deleteData](m-domcharacterdata-deletedata.md) | 텍스트 일부를 삭제합니다. |
| [replaceData](m-domcharacterdata-replacedata.md) | 텍스트의 일부를 제거합니다. |

## 속성

| 속성 | 설명 |
| --- | --- |
| [데이터](p-domcharacterdata-data.md) | 노드의 텍스트 값입니다. |
| [길이](p-domcharacterdata-length.md) | 노드의 문자 수입니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
