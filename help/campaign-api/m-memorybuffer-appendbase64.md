# appendBase64

밑줄 64로 인코딩된 문자열의 데이터를 버퍼 끝에 추가합니다.

```text
appendBase64 (string)
```

## 매개변수

**string** Base 64에서 인코딩되어 버퍼에 추가되는 이진 데이터를 나타내는 문자열입니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [MemoryBuffer](c-memorybuffer.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 게재 메시지
* 유형화 규칙
* 가져오기
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
