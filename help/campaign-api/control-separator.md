# 구분자

텍스트 및 이미지로 구분자를 표시합니다.

![구분 기호 컨트롤](assets/separator.70317a27.png)

## 속성

**방향 - 기본적으로 문자열** 가로

**img - 문자열** 연결된 이미지입니다.

표시할 **레이블 - 문자열** 텍스트입니다.

## 비고

예:

```xml
      <static type="separator" label="Please enter your name here."/>

<static type="separator">Please enter your name here.</static>
```
