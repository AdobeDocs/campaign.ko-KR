# 파일 편집

이 컨트롤을 사용하면 파일 이름을 입력할 수 있습니다.

![FileEdit 컨트롤](assets/fileedit.56228d2a.png)

## 속성

**backColor - string** 배경색(btnshasow, white).

**border - string** 제어하는 동안 테두리 스타일을 변경합니다(단색, 이중, 인세트, 시작, 없음).

**dlgType - string** 파일 선택 창 유형(save, opendir, savedir).

**필터 - 문자열** 필터 목록

**font-size - integer** 글꼴 크기를 변경합니다.

**레이블 - 문자열** 관련 레이블입니다.

**lastPath - 문자열** 파일 선택 창의 경로.

**loadContent - boolean** 파일의 내용을 로드합니다.

**nolabel - 부울** 연결된 레이블을 숨깁니다.

**읽기 전용 - 부울** 컨트롤을 읽기 전용으로 강제 실행합니다.

**필수 - 부울** 필드는 필수입니다.

선택 창의 **제목 - 문자열** 제목

**xpathCopyName - xpath** 파일 이름(확장명 포함)을 저장하는 경로입니다.

**xpathType - xpath** 파일 형식(텍스트 또는 XML)
