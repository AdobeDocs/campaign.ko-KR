# SubmitDeliveryById

(내부 이름에 의해 식별되는) 시나리오에서 게재를 생성하고 제출합니다.

```text
Number deliveryId = SubmitDeliveryById ( Number scenarioId, XML content )
```

## 매개변수

**scenarioId** 템플릿 식별자

템플릿에 추가할 **content** XML 콘텐츠

## 반환 값

템플릿에 추가할 **deliveryId** XML 콘텐츠

**스키마:** [nms:delivery](s-nms-delivery.md)
