# FTP (클래스)

FTP 개체를 사용하면 FTP 프로토콜을 사용하여 여러 작업을 수행할 수 있습니다.

## 방법

| 방법 | 설명 |
| --- | --- |
| [FTP](m-ftp-ftp.md) | FTP 명령을 실행할 새 개체를 만듭니다. |
| [dispose](m-ftp-dispose.md) | 개체에서 사용하는 리소스를 해제합니다. |
| [목록](m-ftp-list.md) | 지정한 디렉터리에 있는 서버의 파일 목록을 반환합니다. |
| [다운로드](m-ftp-download.md) | 서버에서 로컬 파일 또는 메모리로 파일을 다운로드합니다. |
| [업로드](m-ftp-upload.md) | 로컬 파일에서 FTP 서버로 파일을 다운로드합니다. |
| [setFile](m-ftp-setfile.md) | 전송 모드 및 수신 파일을 정의합니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
