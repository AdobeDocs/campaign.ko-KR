# 커밋

연결에 대해 진행 중인 트랜잭션을 승인합니다.

```text
commit ()
```

## 매개변수

없음.

## 반환 값

없음.

## 비고

[begin](m-dbengine-begin.md) 메서드를 사용하여 트랜잭션을 미리 시작해야 합니다.

## 기능

**클래스의 메서드:** [DBEngine](c-dbengine.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
