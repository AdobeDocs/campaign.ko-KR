# Html 텍스트

HTML 콘텐츠를 일반 텍스트로 변환합니다.

```text
String textContent = HtmlToText ( String htmlContent )
```

## 매개변수

변환할 **htmlContent** HTML 콘텐츠

## 반환 값

**textContent** 변환된 텍스트를 반환합니다.
