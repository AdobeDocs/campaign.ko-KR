# EnumerationValue(클래스)

열거형 값의 정의를 나타냅니다.

## 속성

| 속성 | 설명 |
| --- | --- |
| [레이블](p-enumerationvalue-label.md) | 현재 열거형 값에 대한 간단한 설명을 제공하는 문자 문자열을 반환합니다. |
| [설명](p-enumerationvalue-description.md) | 현재 열거형 값에 대한 설명을 제공하는 문자 문자열을 반환합니다. |
| [값](p-enumerationvalue-value.md) | 현재 열거형 값의 값을 제공하는 문자 문자열을 반환합니다. |
| [이름](p-enumerationvalue-name.md) | 현재 열거형 값의 이름을 제공하는 문자 문자열을 반환합니다. |
| [이미지](p-enumerationvalue-image.md) | 현재 열거형 값의 이미지 이름을 제공하는 문자 문자열을 반환합니다. |
| [enabledIf](p-enumerationvalue-enabledif.md) | 현재 열거형 값의 유효성 조건을 제공하는 문자 문자열을 반환합니다. |

## 기능

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
