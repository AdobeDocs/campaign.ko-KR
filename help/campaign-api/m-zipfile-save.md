# 저장

아카이브를 저장합니다.

```text
save ( [filename ] [, overwrite ])
```

## 매개변수

**파일 이름** 보관 이름입니다. 이름이 지정되지 않았거나 비어 있으면 아카이브가 원래 이름으로 저장됩니다.

**덮어쓰기** &#39;false&#39;인 경우 이 이름의 파일이 이미 있으면 보관 파일이 저장되지 않으며 예외가 발생합니다.

## 반환 값

없음.

## 기능

**클래스의 메서드:** [ZipFile](c-zipfile.md)

**다음 위치에서 사용 가능:**

* 콘텐츠 관리
* 게재 속성
* 유형화 규칙
* JSSP
* SOAP 메서드
* 웹 앱
* 워크플로
