# CreateFromCatalog

패키지에서 주문을 생성합니다.

```text
XML localOrder = CreateFromCatalog ( Number catalogId, Number orgUnitId )
```

## 매개변수

**catalogId** 패키지 ID.

**orgUnitId** 로컬 엔터티 ID. (선택 사항)

## 반환 값

**localOrder** 만들어진 순서를 반환합니다.
