# serverName

쿼리 서버의 이름을 반환합니다.

```text
serverName
```

## 비고

예: 다음 URL의 serverName:

```javascript
      http://adobe.com/kr:8080/nms/test.jst?id=1234&param=dummy#aFragment
```

는 다음 문자열을 반환합니다.

```javascript
adobe.com
```

## 기능

**클래스의 속성:** [HttpServletRequest](c-httpservletrequest.md)

**읽기 전용:**

예

**다음 위치에서 사용 가능:**
